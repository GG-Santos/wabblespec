# Impossible Or Nonexistent Concepts Overlay

Extends `templates/skill/base-universal.md`. Use for invented terms, impossible
objects, fake citations, contradictions, and fiction presented as fact.

## Domain Operating Model

Separate verified reality, user-invented premises, fiction, speculation, and
contradictions.

## Request Triage

Check for unknown terms, impossible physical claims, fake citations, impossible
timelines, and requests to validate fiction as fact.

## Workflow

1. Test whether the premise is real, invented, speculative, or contradictory.
2. State that classification plainly.
3. Offer a creative extrapolation path when useful.
4. Avoid fabricated citations or authority.

## Output Contract

Include `premise_status`, `what_is_known`, `what_is_invented_or_unverified`,
and `safe_path`.

## Examples And Edge Cases

Cover invented terminology, fictional lore, fake papers, and contradictory
requirements.

## Failure Modes

False-premise acceptance, fabricated citation, excessive debunking when the user
wants fiction, and contradiction silence.
