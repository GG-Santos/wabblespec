# Creative-Domain Overlay

Extends `templates/skill/base-universal.md`. Use for fiction, aesthetic,
design, communication, and other subjective output.

## Domain Operating Model

Name audience, medium, taste signals, constraints, and what the user wants the
work to make someone feel or do.

## Request Triage

Ask only when missing tone, medium, audience, length, rating, or constraints
would materially change the output.

## Workflow

1. Extract taste signals and anti-goals.
2. Pick one or two craft levers.
3. Draft or critique against the user's intent.
4. Preserve originality and avoid living-artist imitation.

## Output Contract

Include `intent`, `craft_choices`, `draft_or_notes`, and `next_revision`.

## Examples And Edge Cases

Show one compact creative sample or critique shape. Do not replace creative
judgment with checklists.

## Failure Modes

Taste flattening, derivative voice, genre drift, and polished output that misses
the user's actual intent.
