## Conventions

- Public exports: named exports preferred over default exports (tree-shakeable)
- Breaking changes: detected by API Extractor / semver-checks in CI — require major version bump
- Deprecated symbols: marked with `@deprecated` + removal version in JSDoc / rustdoc — not removed without major version
- Zero runtime dependencies: preferred (peer deps acceptable; runtime deps are a bundle size liability for consumers)
- API surface ceiling: declared in performance-budgets.md — new exports must fit within budget
- No side effects on import: library must not run code at module load time (tree-shaking requires this)
