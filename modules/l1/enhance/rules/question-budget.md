# Question Budget

Maximum 3 clarifying questions per Enhance pass.

## Budget allocation

Priority order for question slots:

1. Missing critical dimensions (Task, Target, Format) — highest priority
2. Constraints — especially when complexity is High or scope is broad
3. Success criteria — when no spec artifact exists yet
4. Input — when task implies material to work from but none was provided
5. Context, Audience, Examples — lowest priority; derive or defer

If more than 3 dimensions are unresolved: allocate 3 questions to the highest-priority unresolved dimensions. Leave lower-priority dimensions for downstream resolution (ScopeFrame, Specify, or Interview).

## Question format

Write questions as a numbered list. Each question:
- Targets exactly one dimension
- Is answerable in one sentence
- Does not presuppose an answer

Bad: "What specific file should we modify, and what approach do you prefer?"
Good: "Which file or module should this change be applied to?"

## Zero questions

If all critical dimensions are resolved (present or derived) and the non-critical dimensions are either present or low-enough priority: ask 0 questions and proceed directly to Step 4.

Do not ask questions for the sake of thoroughness. Ask only when an answer is needed to produce a useful enhanced input.

## After user responds

Accept the user's answer as-is. Do not ask follow-up questions within the same pass. If the answer introduces new ambiguity, note it in the enhanced input as an open assumption — do not start a second question round.

Second question round: if the user's answer reveals a new critical gap, one additional pass is permitted. Record it in the receipt as a second pass (`questions_asked` accumulates). Maximum 2 passes total.
