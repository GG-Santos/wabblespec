# Framework-Specific Architecture: Flutter

> **Applies when:** `pubspec.yaml` detected + Flutter SDK declared as dependency.
> Covers Flutter 3.x (Dart 3+). Null safety is mandatory — no legacy null-unsafe code.
> **Version authority:** Flutter 3.19+. Dart 3.x. State management: declare one primary approach.

---

## State Management Declaration [REQUIRED]

Flutter has no built-in global state management. Declare one primary approach before implementation.

| Approach | Best for | Avoid when |
|---|---|---|
| **Riverpod 2** | Most apps — testable, compile-safe, no context required | Team unfamiliar; adds learning curve |
| **Bloc / Cubit** | Event-driven state, complex flows, large team with strict conventions | Simple apps — excessive boilerplate |
| **Provider** | Simple sharing, legacy codebases | New projects — prefer Riverpod |
| **GetX** | Rapid prototypes | Production — anti-patterns around global state |
| **ValueNotifier / ChangeNotifier** | Single-widget local state | Cross-widget state |

**Declared state management:** ___

## Widget Tree Fundamentals

Flutter's UI is a tree of Widgets. Widgets are immutable descriptions — the framework reconciles changes via the Element tree.

```dart
// StatelessWidget — no mutable state; rebuilds when parent passes new config
class ProductCard extends StatelessWidget {
  const ProductCard({ super.key, required this.product });
  final Product product;

  @override
  Widget build(BuildContext context) {
    return Card(
      child: ListTile(
        title: Text(product.name),
        subtitle: Text('\$${product.price.toStringAsFixed(2)}'),
      ),
    );
  }
}

// StatefulWidget — owns mutable state via State<T>
// Use only when: animation controller, form state, focus node, scroll controller
class CounterButton extends StatefulWidget {
  const CounterButton({ super.key });

  @override
  State<CounterButton> createState() => _CounterButtonState();
}

class _CounterButtonState extends State<CounterButton> {
  int _count = 0;

  @override
  Widget build(BuildContext context) {
    return ElevatedButton(
      onPressed: () => setState(() => _count++),
      child: Text('Count: $_count'),
    );
  }
}
```

**Rule:** `StatefulWidget` is for local ephemeral state only — form controllers, animations, focus. Business logic and shared state live in the state management layer, not in `State<T>`.

## Riverpod 2 (if declared)

```dart
// providers/products_provider.dart
import 'package:riverpod_annotation/riverpod_annotation.dart';
part 'products_provider.g.dart';  // generated by build_runner

@riverpod
Future<List<Product>> products(ProductsRef ref) async {
  final repo = ref.watch(productRepositoryProvider);
  return repo.fetchAll();
}

@riverpod
class CartNotifier extends _$CartNotifier {
  @override
  List<CartItem> build() => [];

  void add(Product product) {
    state = [...state, CartItem(product: product, quantity: 1)];
  }

  void remove(String productId) {
    state = state.where((item) => item.product.id != productId).toList();
  }
}

// Usage in widget:
class ProductsScreen extends ConsumerWidget {
  const ProductsScreen({ super.key });

  @override
  Widget build(BuildContext context, WidgetRef ref) {
    final products = ref.watch(productsProvider);
    return products.when(
      data: (list) => ProductList(products: list),
      loading: () => const CircularProgressIndicator(),
      error: (e, _) => ErrorView(message: e.toString()),
    );
  }
}
```

**Code generation:** Riverpod 2 with `@riverpod` annotation requires `build_runner`. Run `dart run build_runner build` after adding/modifying providers. Generated files (`.g.dart`) are committed to the repo.

## Bloc / Cubit (if declared)

```dart
// Cubit (simpler — no events, just methods)
class CartCubit extends Cubit<CartState> {
  CartCubit() : super(CartState.initial());

  void addItem(Product product) {
    emit(state.copyWith(items: [...state.items, CartItem(product: product)]));
  }
}

// Bloc (event-driven — for complex state machines)
class AuthBloc extends Bloc<AuthEvent, AuthState> {
  AuthBloc(this._authRepository) : super(const AuthState.initial()) {
    on<LoginRequested>(_onLoginRequested);
    on<LogoutRequested>(_onLogoutRequested);
  }

  FutureOr<void> _onLoginRequested(LoginRequested event, Emitter<AuthState> emit) async {
    emit(state.copyWith(status: AuthStatus.loading));
    try {
      final user = await _authRepository.login(event.email, event.password);
      emit(state.copyWith(status: AuthStatus.authenticated, user: user));
    } catch (e) {
      emit(state.copyWith(status: AuthStatus.error, errorMessage: e.toString()));
    }
  }
}
```

## Navigation (go_router)

```dart
// router/app_router.dart
import 'package:go_router/go_router.dart';

final appRouter = GoRouter(
  initialLocation: '/',
  redirect: (context, state) {
    final isAuthenticated = /* check auth */;
    if (!isAuthenticated && state.matchedLocation != '/login') return '/login';
    return null;
  },
  routes: [
    GoRoute(
      path: '/',
      builder: (context, state) => const HomeScreen(),
    ),
    GoRoute(
      path: '/products/:id',
      builder: (context, state) => ProductDetailScreen(
        productId: state.pathParameters['id']!,
      ),
    ),
  ],
);

// Navigation calls:
context.go('/products/123')      // replace current route
context.push('/products/123')    // push onto stack
context.pop()                    // pop — use instead of Navigator.pop
```

## Platform Channels (native interop)

```dart
// When no plugin exists — call native iOS/Android code directly
static const _channel = MethodChannel('com.example.app/custom');

Future<String> getNativeDeviceId() async {
  try {
    return await _channel.invokeMethod<String>('getDeviceId') ?? '';
  } on PlatformException catch (e) {
    throw Exception('Failed to get device ID: ${e.message}');
  }
}
```

```swift
// iOS (AppDelegate.swift)
let channel = FlutterMethodChannel(name: "com.example.app/custom", binaryMessenger: ...)
channel.setMethodCallHandler { call, result in
  if call.method == "getDeviceId" {
    result(UIDevice.current.identifierForVendor?.uuidString)
  }
}
```

**Rule:** Prefer existing Flutter plugins over custom platform channels. Write a channel only when no maintained plugin exists for the native capability. Document the channel name as a constant — do not inline strings.

## pubspec.yaml Governance

```yaml
# pubspec.yaml — version constraints are required on all dependencies
dependencies:
  flutter:
    sdk: flutter
  riverpod: ^2.5.0         # carets allow compatible updates
  go_router: ^13.0.0
  freezed_annotation: ^2.4.1

dev_dependencies:
  build_runner: ^2.4.8
  riverpod_generator: ^2.3.9
  freezed: ^2.4.5
  flutter_lints: ^3.0.0    # enforced — do not remove

flutter:
  uses-material-design: true
  assets:
    - assets/images/
    - assets/fonts/
  fonts:
    - family: Inter
      fonts:
        - asset: assets/fonts/Inter-Regular.ttf
        - asset: assets/fonts/Inter-Bold.ttf
          weight: 700
```

**Governance rules:**
- All dependency versions must have explicit constraints (no `any`).
- `flutter_lints` must remain in dev_dependencies — removing it is a lint violation.
- Assets must be declared before they can be loaded — undeclared assets fail at runtime.

## GWT Acceptance Scenarios

```
Given: a widget uses state from Riverpod
When: the provider's value changes
Then: only the widgets that watch that provider rebuild
      AND widgets that do not watch it do not rebuild
      AND the provider is accessed via ref.watch (not ref.read) in build methods

Given: a platform channel is called
When: the native implementation throws an exception
Then: the Dart code catches PlatformException specifically
      AND the error is surfaced to the user as a message (not a crash)
      AND the channel name constant is defined once in a constants file

Given: the app runs on both iOS and Android
When: any screen renders text
Then: all text uses the declared font family from pubspec.yaml
      AND font files are present at the declared asset paths
      AND no hardcoded font sizes are used — only ThemeData text styles
```
