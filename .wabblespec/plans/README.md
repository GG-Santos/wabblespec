# .wabblespec/plans/

Planning artifacts for the current project. All files use a prefix naming convention.

## Naming convention

| Prefix | Purpose | Example |
|--------|---------|---------|
| `roadmap-*.md` | Long-horizon direction, no hard deadlines | `roadmap-l8-evolution.md` |
| `milestone-*.md` | Specific done-condition checkpoint | `milestone-100-receipts.md` |
| `phase-*.md` | Sequential phase plan with wave breakdowns | `phase-integration.md` |
| `task-*.md` | Active task card for current pipeline run | `task-card.md` |
| `wave-*.md` | Current wave plan produced by Decompose | `wave-current.md` |
| `decisions-*.md` | Architectural decision records | `decisions-phase-0.md` |
| `gateway-*.md` | Gateway-specific plans | `gateway-leaf.md` |

## Current files

- `wave-current.md` — current wave plan (written by Decompose)
- `phase-integration.md` — integration phase plan
- `decisions-phase-0.md` — Phase 0 architectural decisions
- `gateway-leaf.md` — gateway leaf plan (COMPLETE)
