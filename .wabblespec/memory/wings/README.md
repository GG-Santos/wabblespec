# Memory Wings

Evidence drawers are organized as: `wings/{wing}/rooms/{room}/drawers/{drawer-id}.json`

Naming convention: `modules/l5/memory/rules/drawer-naming.md`
Schema: `_shared/schemas/drawer.schema.json`

Suggested wings: architecture, requirements, implementation, infrastructure, research, decisions.
Add wings as needed — there is no fixed registry. The wing name is just a directory.
