# Structure Templates

Approved content structures. Each maps to one or more content types.

## AIDA

**Applies to:** landing pages, marketing emails, awareness campaigns.

| Section | Purpose |
|---|---|
| Attention | Hook: a surprising stat, a sharp question, or a concrete problem |
| Interest | Context: why this matters now, who it affects |
| Desire | Proof: how the solution works, what makes it different, evidence |
| Action | CTA: exactly what to do next and what happens when they do it |

## Problem-Solution

**Applies to:** landing pages, blog posts, case studies, awareness.

| Section | Purpose |
|---|---|
| Problem | Name the pain precisely — specific, not generic |
| Why it happens | Root cause: why does this problem exist? |
| What people try | Failed alternatives — builds credibility and contrast |
| Solution | How this product/approach solves it differently |
| Evidence | Proof that it works (metrics, case, demo) |
| CTA | Next step |

## Tutorial

**Applies to:** tutorials, how-to guides, onboarding docs.

| Section | Purpose |
|---|---|
| Objective | One sentence: what the reader will be able to do after |
| Prerequisites | What is required before starting |
| Steps (numbered) | Single-action, sequential steps |
| Verification | How to confirm it worked |
| Troubleshooting | Common failure modes and their fixes |

## Inverted pyramid (journalism)

**Applies to:** news, release announcements, product updates.

| Section | Purpose |
|---|---|
| Lead | The most important fact first |
| Key details | Supporting context for the lead |
| Background | History, context, secondary information |
| Appendix | Data, links, additional material |

## Storybrand (for case studies and brand storytelling)

**Applies to:** case studies, brand narratives, awareness campaigns targeting business buyers.

| Section | Purpose |
|---|---|
| Character | The customer: who they are and what they want |
| Problem | What is blocking them (external, internal, philosophical) |
| Guide | The product/company as the guide, not the hero |
| Plan | How the guide helps — simple, clear steps |
| Action | The CTA |
| Stakes | What they gain / what they avoid |

## Section selection rule

Select the structure that matches the primary goal. Do not combine structures within one document. If the goal is mixed (e.g., "landing page that tells a story"), select the structure that serves the conversion goal and apply story elements within it — not a parallel structure.
