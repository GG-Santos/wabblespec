## Process Architecture

### Electron

```
Main Process (Node.js)
  ├── app lifecycle (ready, activate, quit)
  ├── BrowserWindow management
  ├── IPC handlers (ipcMain)
  ├── Native APIs (fs, shell, dialog, net)
  ├── Auto-updater
  └── System tray / menu bar

Preload Script (contextBridge)
  └── Exposes validated API to renderer

Renderer Process (Chromium — sandboxed)
  └── UI (React/Vue/Svelte/vanilla)
      └── Calls preload API only
```

### Tauri

```
Rust Backend (sidecar process)
  ├── Commands (tauri::command)
  ├── Events (tauri::event)
  ├── File system access
  └── OS APIs

WebView Frontend
  └── UI (any web framework)
      └── Calls Tauri commands via invoke()
```

## IPC Design (Electron)

**contextBridge API surface** — the only interface between renderer and main:

```typescript
// preload.ts
import { contextBridge, ipcRenderer } from 'electron'

contextBridge.exposeInMainWorld('electronAPI', {
  getConfig: () => ipcRenderer.invoke('get-config'),
  openFile: () => ipcRenderer.invoke('open-file'),
  // list only what renderer actually needs
})
```

**Main process handlers:**
```typescript
ipcMain.handle('get-config', async (event) => {
  // validate event.senderFrame.url is from our app
  // return config data
})
```

**Never expose:**
- `ipcRenderer` itself (lets renderer call arbitrary channels)
- `require` or Node.js modules
- File system paths outside declared scope

## Data Storage Strategy

| Data type | Storage location | Format |
|---|---|---|
| User preferences | `app.getPath('userData')/prefs.json` | JSON |
| App state | `app.getPath('userData')/state.json` | JSON |
| User documents | User-selected path via dialog | User-owned |
| Sensitive data | OS keychain (via `keytar` or Tauri's `stronghold`) | Encrypted |
| Cache | `app.getPath('userData')/cache/` | Platform-specific |

**Never store sensitive data in plain JSON files.** Use OS keychain.

## Auto-Updater Architecture

```
App launch
  └── updater.checkForUpdates()
        ├── Fetch update manifest from update server
        ├── Verify manifest signature
        ├── Compare version with current
        └── If update available:
              ├── Download update package
              ├── Verify package signature
              └── Prompt user → install on restart
```

**Update server:** GitHub Releases (standard for electron-updater/Tauri updater).

**Update manifest:** `latest.yml` (Windows/Linux) or `latest-mac.yml` (macOS) — generated by build tool.

**Signature:** electron-updater uses code signing cert. Tauri uses `updater.pubkey` in tauri.conf.json.
