# Interview — Acceptance Criteria

## BLOCK: absent recipe receipt

Given `recipe-receipt.json` is absent,
When Interview is invoked,
Then Interview surfaces a DEPENDENCY error naming Recipe.
Then Interview does not ask generic questions without a target.
Then no intent.md is written.

## Happy path: ambiguity resolution

Given a Recipe output with confidence < 0.8 or declared ambiguity dimensions,
When Interview runs,
Then at most 3 questions are asked in the first batch.
Then Interview waits for answers before sending the next batch.
Then when all ambiguity is resolved, Interview stops — it does not exhaust all 9 dimensions.
Then intent.md is written to `.wabblespec/plans/intent.md`.
Then a receipt is written.

## Product-context.md open questions: covered first

Given `product-context.md` exists with Open Questions listed,
When Interview prepares its first question batch,
Then those open questions are covered before Interview generates its own questions.

## Socratic rule: no leading questions

Given any question generated by Interview,
Then the question is phrased as an open question (e.g., "What type of interface does this expose?").
Then the question is never phrased as a leading yes/no suggestion (e.g., "Is this a REST API?").

## Max 3 questions per batch

Given Interview has more than 3 ambiguity dimensions to resolve,
When the first batch is sent,
Then at most 3 questions are asked.
Then the remaining dimensions are addressed in subsequent batches after answers are received.

## Stop when resolved

Given all ambiguity is resolved before all 9 dimensions have been asked about,
When Interview checks for remaining unresolved dimensions,
Then Interview stops and writes intent.md.
Then Interview does not continue asking questions for resolved dimensions.

## No re-asking answered questions

Given a dimension was answered in a prior batch,
When subsequent batches are generated,
Then that dimension is not asked about again.

## Cold start: no spec artifacts (High complexity)

Given `specs/` is empty and `task-card.md` is absent,
When Interview runs for a High complexity task,
Then Interview generates opening questions from the recipe target and complexity level.
Then no DEPENDENCY error is surfaced for absent specs — Interview is designed to run before specs exist.

## intent.md required fields

Given any completed Interview run,
Then intent.md contains: Session timestamp, Resolved dimensions list, Unresolved dimensions list, and Confirmed Answers section with question/answer/confidence per resolved dimension.

## Receipt

Given any successful Interview run,
Then a receipt is written to `.wabblespec/receipts/`.
