# Domain Injection Overlay

Extends `templates/skill/base-universal.md`. Use when a category profile exists
or strong domain keywords can be inferred.

## Domain Operating Model

Name domain signals, user nouns, practitioner criteria, and assumptions that
must be labeled.

## Request Triage

Ask only for domain facts that change the answer, safety boundary, or output
format.

## Workflow

1. Apply the domain's reasoning pattern.
2. Use domain-specific output fields.
3. Check category risk tags before answering.
4. End with the domain's proof or next check.

## Output Contract

Use concrete domain fields rather than generic `summary` / `details` sections.

## Examples And Edge Cases

Include one representative normal case and one case where domain ambiguity
changes the result.

## Failure Modes

Generic output, wrong domain frame, assumption leak, and missing practitioner
criteria.
